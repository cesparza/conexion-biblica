# Para cualquier instancia de Claude que abra este repo

Este repo lo trabajan dos sesiones de Claude distintas sobre la misma carpeta: una de
Cowork (por el puente a este Mac) y una de Claude Code corriendo directo aquí. Las dos ven
el mismo git, así que el código nunca se desincroniza entre ellas. Lo que SÍ se puede
perder es el porqué de una decisión, porque eso vive en la memoria de Cowork (el Project
"Daniel" en claude.ai — docs y memoria de proyecto), y esta sesión de Claude Code no puede
leer eso.

**Respaldo cruzado, fuera de git y fuera de cualquier Project de claude.ai:**

`~/Library/Mobile Documents/com~apple~CloudDocs/Claude-Respaldo/proyecto-daniel/`

Ahí está `estado-conexion-biblica.md` (arquitectura y estado vigente de la app),
`memoria-proyecto-conexion-biblica.md` (decisiones puntuales de la memoria de proyecto,
como dónde vive la clave del director), `LEEME.md` (índice) y el resto de los documentos.
Es texto plano: cualquier instancia con esa carpeta accesible lo lee sin depender del
Project de claude.ai ni de ningún chat que se pueda perder.

**Regla:** cuando una sesión decide algo de arquitectura, cierra una versión o descubre un
hallazgo importante, lo escribe en ese momento tanto en el Project de Cowork como en ese
archivo de iCloud — no solo en uno de los dos. Si estás en Claude Code y no tienes acceso a
esa carpeta, pídele a Camilo que la comparta o que pegue el contexto que falte; no asumas
que el repo por sí solo cuenta la historia completa de por qué algo se hizo así.
